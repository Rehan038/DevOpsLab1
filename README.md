# Explore India

A simple static travel website showcasing destinations across India, including the Taj Mahal, Kerala Backwaters, and Goa Beaches.

## Features

- Responsive-ready HTML structure for the travel homepage
- Destination cards for popular Indian locations
- Interactive "Explore More" button powered by JavaScript
- Separate CSS and JavaScript files for easy maintenance

## Project Structure

```text
travel-india/
└── travel-india/
    ├── index.html
    ├── css/
    │   └── style.css
    ├── images/
    └── scripts/
        └── script.js
```

## Run Locally

No build tools or dependencies are required.

1. Open `travel-india/travel-india/index.html` directly in a browser, or
2. Serve the project with any static file server, for example:

```bash
cd travel-india/travel-india
python -m http.server 8000
```

Then visit <http://localhost:8000>.
